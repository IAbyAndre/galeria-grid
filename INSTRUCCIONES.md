# 🖥️ Servidor Local - Galería Grid

## Iniciar servidor
```bash
cd /Users/andre/Desktop/AppWeb
node servidor.js
```
Luego abrir: http://localhost:8080

## Detener servidor
```bash
kill $(lsof -ti :8080)
```
